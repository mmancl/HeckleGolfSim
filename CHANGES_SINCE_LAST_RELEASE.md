### Bug Fixes
- **Remote Multiplayer Shot Replay Accuracy & Course Alignment**: Resolved an issue in online multiplayer where opponent shot replays flew wildly off target (such as 100+ yards into adjacent fairways or backwards across the screen), causing players to appear far away on other devices even after hitting the green or landing inside the gimme circle. Differences in course map generation between devices are now automatically detected and harmonized in real time, ensuring that remote shot replays smoothly trace along the fairway and green to the exact target location, and that remaining distances, turn order, and gimme awards stay perfectly in sync across all devices. Added dynamic ground contour hugging during remote shot putts and approach landings so that balls follow green undulations naturally without floating or sinking into the turf.
- **OpenStreetMap Course Download Resilience & macOS Connectivity Fix**: Resolved an issue where downloading custom golf courses on macOS and other platforms could fail or prematurely time out with SSL authentication and timeout errors. Replaced decommissioned OpenStreetMap mirror endpoints with active servers, updated secure connection protocols to resolve macOS TLS handshake failures, increased server response wait windows for busy queue times, and added progressive retry delays to ensure course map downloads complete reliably.
- **Android Release Startup Failure & Missing Assets Fix**: Fixed a critical issue where the latest Android release crashed immediately on launch with `"Error! Unable to setup the Godot engine! Aborting..."` and appeared as "godot-project" with the default Godot logo. The automated release pipeline now fully exports and packages all game scenes, course assets, C# assemblies, and visual themes into the Android App Bundle (`.aab`) with the proper application branding and launcher icons, accompanied by automated pre-deployment bundle integrity checks to ensure Google Play releases are complete and verified.
- **macOS Universal Build Packaging & Truncation Fix**: Resolved an issue where the macOS build was prematurely terminated during export, resulting in an incomplete 15 MB archive instead of the full ~500 MB universal application package. Completion detection now waits for the full universal binary compression and codesigning sequence (`[DONE] export`), and strict file size and archive integrity verifications have been added to prevent undersized or corrupted macOS packages from ever being published.
- **Automated Multiplatform Release Pipeline Artifact Resolution**: Resolved a workflow bug where reusing previous build run artifacts incorrectly defaulted to old published GitHub releases and suppressed Google Play deployments. Fresh build artifacts from specified run IDs are now prioritized and automatically deployed to Google Play tracks.
- **Online Multiplayer Tournaments Permission & Error Display Fix**: Resolved an issue where hosting or browsing online tournaments failed with permission denied errors. Added security rules and database indexes for creating, joining, and listing tournaments and scorecards, and improved in-game error handling so that network and permission messages display clean, player-friendly guidance instead of raw technical codes or JSON.
