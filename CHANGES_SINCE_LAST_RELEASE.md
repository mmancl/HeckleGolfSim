### Bug Fixes
- **Windows & macOS Build Pipeline Reliability**: Restored synchronous process streaming and graceful package finalization during Godot headless exports, ensuring non-fatal teardown warnings do not trigger spurious build failures.
- **Fixed Plant Asset Scene Encoding in Windows Builds**: Resolved a parser error (`Parse Error: Expected '['`) caused by hidden UTF-8 Byte Order Marks (BOM) in exterior plant static body scenes.
- **Online Multiplayer Realtime Event Transmission & Turn Handshake**: Fixed a critical bug where online shot events and turn updates were never published to the cloud backend after hitting the ball due to an uninitialized database client reference, leaving remote players perpetually waiting on the opponent's first shot. Shot events and turn transitions are now published reliably with active cloud verification.
- **Fixed Release Build Freezes on Windows**: Resolved an issue where headless Godot exports would hang on Windows after finalizing the game package (`[DONE] savepack`) due to Mono domain teardown deadlock. Added automatic package completion detection and process lifecycle management to guarantee smooth automated builds.
- **Online Multiplayer Shot Replay & Turn Progression**: Fixed an issue where matches would get stuck on "Waiting for player to hit..." after the first shot. Opponent shots now cleanly replay with ball tracer trails and follow-camera tracking on remote screens before handing over the next turn.
- **Launch Monitor Readiness HUD in Multiplayer**: The "Ball Ready" status indicator and ready placement box are now hidden when waiting for your opponent to hit or when viewing a remote shot replay, reappearing only when it is your turn to hit.
- **Menu Screen Readiness Indicator**: Fixed an issue where the launch monitor "Ball Ready" indicator and square ready zone incorrectly displayed inside multiplayer lobby setup screens, leaderboards, and menu pages.
